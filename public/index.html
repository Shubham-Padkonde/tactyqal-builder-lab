GOOD QUESTIONS

Curiosity
is the prerequisite.

Do I need to know how to code?

No prior coding experience is required by the program. AI and no-code tools help beginners focus on ideas and build a first version.

How much time should I set aside?

The existing program describes about 2–3 hours per week, including a one-hour mentoring session. Confirm the schedule with Tactyqal before joining.

What can I build?

Start with an interest or a problem you understand. Your mentor can help you choose a manageable first product, from a learning tool to a community project.
